# 💸 Personal Finance Roast AI

An AI-powered multi-agent system that analyzes your income and expenses, roasts your spending habits 🔥, and generates a structured 3-month savings plan using CrewAI + Streamlit.

---

## 🚀 Features

- 📊 Income & expense analysis using AI agents  
- 🔥 Brutal but funny financial roast  
- 🧠 3-month realistic savings plan  
- 🧾 Custom savings rate calculator tool  
- 🎨 Streamlit web UI for easy interaction  
- 📄 Markdown report generation (`finance_report.md`)  
- 🤖 Multi-agent AI workflow (CrewAI)

---

## 🎨 Streamlit UI (Frontend)

This project includes a **Streamlit-based web interface** that makes the AI system easy to use without running terminal commands.

### 💡 What Streamlit provides:
- Simple web-based UI
- Input fields for:
  - Monthly Income 💰
  - Monthly Expenses 💸
- One-click execution button (“Generate Roast 🔥”)
- Real-time AI response display
- Downloadable finance report
- No need for terminal interaction

### ▶️ How to run Streamlit app:

```bash
streamlit run streamlit_app.py
